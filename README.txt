# E-COMMERCE MANAGEMENT SYSTEM

**Developed for:** Besant Technologies  
**Developed by:** Uma TR

## 1. Project Description
The E-Commerce Management System is a console-based application developed using Core Java. It helps manage online shopping activities, including customer registration, product management, shopping cart operations, discounts, payments, and order tracking.

## 2. Technologies Used
- Java (Core Java)
- Object-Oriented Programming (OOP)
- Java Collections Framework
- ArrayList, HashMap and other collection classes
- Exception Handling
- IntelliJ IDEA

## 3. Main Features

### Customer Module
- Customer registration and login
- View and search products
- Add, remove and update cart items
- View cart and calculate total amount
- Apply discounts
- Choose payment methods
- View and cancel eligible orders

### Admin Module
- Admin login
- Add, view, search and update products
- Manage product prices and stock
- Remove products
- View customer orders
- Manage order status

### Payment and Order Management
- UPI payment
- Card payment
- Cash on Delivery (COD)
- Order confirmation and tracking
- Order shipping and delivery
- Stock management

## 4. Project Structure
- `src/` – Contains the Java source files.
- `model/` – Contains user, product, cart and order classes.
- `service/` – Contains application business logic.
- `payment/` – Contains payment interface and implementations.
- `Main.java` – Entry point of the application.

## 5. How to Run the Project
1. Install JDK 23 or a compatible JDK.
2. Install IntelliJ IDEA.
3. Extract the project ZIP file.
4. Open the extracted project folder in IntelliJ IDEA.
5. Allow IntelliJ IDEA to load the project.
6. Open `src/Main.java`.
7. Click the Run button to execute the application.
8. Follow the instructions displayed in the console.

## 6. Database Information
This project uses in-memory Java collections to store application data. It does not require an external database such as MySQL. Data is reset when the application is closed.

## 7. Important Note
The payment methods are simulated for demonstration and learning purposes. No real financial transactions are performed.

## 8. Conclusion
This project demonstrates the practical implementation of Core Java concepts and object-oriented programming through an E-Commerce Management System.
